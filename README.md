# oracle-ai-vector-search-lab

Mini-laboratório público de Oracle AI Vector Search: tabela de chamados de suporte fictícios com coluna VECTOR, busca semântica com filtro por cliente e período, rodando em Docker local (Oracle Database 23ai Free) e validado no Autonomous Database (OCI).

Status: em construção. Jira: projeto OAIVS.

Todos os dados são 100% fictícios. Nenhum segredo, wallet ou credencial é versionado.
